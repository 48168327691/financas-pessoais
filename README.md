# Finanças Pessoais

Aplicativo Windows para acompanhar contas, lançamentos, investimentos e extratos. Esta é uma instalação independente do ICS CONTROLE FINANCEIRO.

## Baixar e usar

Abra **Releases** neste repositório e baixe o ZIP da versão mais recente para Windows. Extraia **todos** os arquivos para uma pasta e execute `Finanças Pessoais.exe`. O pacote inclui o runtime Java necessário.

Cada usuário começa com uma base própria e cadastra suas contas. O aplicativo não abre nem copia o banco do ICS. Dados financeiros não fazem parte do código nem do ZIP distribuído.

O código completo é disponibilizado como um ZIP separado na mesma versão publicada. Um atalho criado em outro computador não substitui o ZIP para distribuição.
